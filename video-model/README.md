# 视频任务查询

H3 和 Video SR 提交成功后，页面保留服务端任务 ID。状态查询采用短请求和重试：网络断线、超时、HTTP 429 或 5xx 不等于视频生成失败，页面保持上次进度并继续查询。自动等待最长 40 分钟；停止等待不会取消后台任务。

任务状态区域的“手动查询”仅查询已有 Job。与自动查询共用进行中的请求，不重新提交 H3，不额外创建 SR，也不取消任务。任务完成后，可重新加载视频结果；视频文件加载失败不会改变服务端已完成状态。非暂时性错误（如鉴权失败）暂停查询，可修正 Request headers 后再次手动查询。

关闭或刷新页面后，可在历史记录中“刷新状态”和下载视频。本次修改不改变客户 API、请求参数或后台部署。

视频结果和历史下载使用带鉴权的 content 接口；暂时性网络/超时/429/5xx 错误最多尝试三次 GET，包括读取文件期间断线。重试耗尽仍保留 completed/100%，显示“视频已生成，结果加载失败”，不重复生成或扣费。401/403/404 不自动重试。发布资源版本为 `20261003-video-result-r2`。

验证：`node --test video-model/*.test.cjs`。
